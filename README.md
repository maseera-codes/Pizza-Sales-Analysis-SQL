# Pizza Sales Analysis | SQL & MySQL

## Project Overview

This project analyzes PizzaHut sales data using SQL and MySQL Workbench to uncover sales trends, customer preferences, and business insights.

The analysis covers total orders, revenue, pizza quantities, pizza sizes, categories, ordering patterns, and top-performing pizza types.

## Tools & Technologies

- MySQL
- SQL
- MySQL Workbench

## Dataset

The dataset contains four related tables:

- `orders`
- `order_details`
- `pizzas`
- `pizza_types`

## Analysis Performed

The project answers several business questions, including:

- What is the total number of orders?
- What is the total revenue generated?
- Which is the highest-priced pizza?
- What is the most commonly ordered pizza size?
- What are the top 5 most ordered pizza types?
- What is the total quantity ordered by pizza category?
- How are orders distributed by hour?
- What is the average number of pizzas ordered per day?
- Which pizza types generate the highest revenue?
- What percentage of total revenue comes from each pizza category?
- What are the top 3 pizza types by revenue within each category?

## SQL Concepts Used

- SELECT
- WHERE
- JOIN
- GROUP BY
- ORDER BY
- Aggregate Functions
- Subqueries
- Window Functions
- RANK()
- LIMIT

## Key Findings

- Total orders analyzed: **21,350**
- Total revenue generated: **817,860.05**
- The most common pizza size was **Large (L)**.
- The analysis identified the top-performing pizzas based on quantity and revenue.
- Pizza categories were compared based on quantity and revenue contribution.
- Ordering patterns were analyzed by hour of the day.

## Project Files

- `pizza_sales_analysis.sql` — SQL queries used for the analysis
- `Pizza-Sales-Analysis.pdf` — Project presentation containing queries, results, and conclusions

## Conclusion

This project demonstrates how SQL can be used to transform raw sales data into meaningful business insights. The analysis can support areas such as inventory planning, promotions, menu decisions, and sales performance analysis.
